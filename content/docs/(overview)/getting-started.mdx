# Getting Started with TaiChi112 Docs

Welcome to the **TaiChi112 Platform Hub**. This platform is designed to house multiple disparate domains of knowledge in a single, unified interface.

## 🧭 Navigation Basics

To avoid cognitive overload, the content is split into **Isolated Domains**. 

1. **Root Toggle (Dropdown):** At the top of the sidebar, you will find a dropdown menu. Use this to switch between major domains like `Computer Science`, `Business`, or `Finance`.
2. **Domain Isolation:** When you select a domain, the sidebar will dynamically update to show *only* the content relevant to that specific field. 
3. **Bento Cards:** You can also use the interactive Bento cards on the [Overview](./) page to quickly jump into a domain.

## 🔍 Search

Use the `Cmd + K` (Mac) or `Ctrl + K` (Windows) shortcut to open the global search modal. The search feature looks through all domains, so you can easily find what you need even if you aren't currently in that domain's view.

## 🌗 Appearance

TaiChi112 Docs supports both Light and Dark modes. The platform will automatically respect your system preferences, but you can manually toggle the theme using the icon at the bottom of the sidebar.
