# Data Mining Exercise 7

For this problem, it is doing **Min-Max Normalization**. Let's see the answer with a detailed step-by-step method.

---

## Answer

<Callout title="✅ Solution" type="success">
The new value is **3**
</Callout>

---

## Step-by-Step Method

### Min-Max Normalization Formula

$$v' = \frac{v - \min_{old}}{\max_{old} - \min_{old}} \times (\max_{new} - \min_{new}) + \min_{new}$$

### 1. Define variables from the problem

$$v (\text{Old value}) = 600$$

$$\min_{old} (\text{Old min}) = 200$$

$$\max_{old} (\text{Old max}) = 1,000$$

$$\min_{new} (\text{New min}) = 1$$

$$\max_{new} (\text{New max}) = 5$$

### 2. Substitute into the formula

$$v' = \frac{600 - 200}{1000 - 200} \times (5 - 1) + 1$$

### 3. Calculate part by part

**First part (Find the proportion position):**

$$\frac{400}{800} = 0.5$$

<Callout title="💡 Meaning" type="info">
Means 600 is exactly in the middle between 200 and 1000.
</Callout>

**Second part (Scale to the new range):**

$$0.5 \times 4 = 2$$

**Third part (Add the new starting value):**

$$2 + 1 = \mathbf{3}$$

## Intuitive Check

If you don't want to memorize the formula, try imagining a number line:

<Callout title="📊 Visual thinking" type="info">
**Old range:** 200 to 1,000 (Distance 800)
- Value 600 is exactly the **midpoint** ($200 + 400 = 600$)

**New range:** 1 to 5 (Distance 4)
- The midpoint of 1 to 5 is exactly **3** ($1 + 2 = 3$)
</Callout>

### Conclusion

<Callout title="✅ Answer" type="success">
The answer is definitely **3**.
</Callout>
