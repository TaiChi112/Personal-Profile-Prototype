# Data Mining Exercise 1

## Problem: Predict "Which customers are likely to change their provider next month?"

## 1. Data Selection

We don't need to pull all the data in the company's universe. We only select data that is likely to affect the decision to change providers.

**Selected:**
- Call history
- Billing amount
- Calls to Call Center
- Promotion type

**Not selected:**
- First and last name (unrelated to the decision)
- ID card number
- Favorite color

## 2. Data Preprocessing

Raw data is often dirty. We need to handle it first.

### 🔍 Missing Values
- **Problem:** Customer 102's `Last_Month_Usage` data is missing (NULL).
- **Solution:** Mean Imputation or drop it.
  - Here, let's assume we fill in the mean = **40 GB**.

### ⚡ Noise/Outlier
- **Problem:** Suppose Customer 104's internet usage last month was 200GB (abnormally high).
- **Solution:** Check if it's an error or actual usage.
  - If actual usage → Keep it, because they might be a VIP group.

### Result after Cleaning:
- **ID 102:** `Last_Month_Usage` changed from `NULL` → `40 GB`

## 3. Data Transformation

This step involves transforming data to make it easier for Algorithms to understand and learn.

### 🔨 Feature Construction

**Create `Usage_Drop_Rate`:**
```
Usage_Drop_Rate = (Last month - This month) / Last month
```

**Reason:** A sharp drop in usage might mean they've started using another provider's SIM.

### 📊 Normalization

**Problem:** `Monthly_Bill` (thousands) and `Calls_to_Support` (single digits) have scales that are too different.

**Solution:** Scale everything to a range of **0-1** (Min-Max Scaling).

### 🔢 Encoding

| ID  | Norm_Bill | Norm_Support_Calls | Usage_Drop_Rate    | Is_Monthly_Contract | Churn (Target) |
| --- | ---

------ | ------------------ | ------------------ | ------------------- | -------------- |
| 101 | 0.3       | 0.0                | 0.0 (Constant)     | 0                   | No             |
| 102 | 0.5       | 1.0 (Frequent calls)| 0.6 (Large drop)   | 1                   | Yes            |
| 103 | 0.1       | 0.0                | 0.0                | 1                   | No             |
| 104 | 1.0       | 0.2                | 0.5 (Drop)         | 0                   | Yes            |
