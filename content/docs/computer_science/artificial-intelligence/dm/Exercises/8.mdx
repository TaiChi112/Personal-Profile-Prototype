## Question 5: Selecting Attribute A or B

### Data Summary

Total data count **10 rows**

- **Class (+):** 4 people (Rows 1, 2, 3, 5)
- **Class (-):** 6 people (Rows 4, 6, 7, 8, 9, 10)

---

### 5a. Calculate Information Gain (Choose A or B?)

#### Entropy Formula

$$H(S) = -p_+ \log_2 p_+ - p_- \log_2 p_-$$

#### Entropy of Parent (P)

$$p_+ = \frac{4}{10} = 0.4, \quad p_- = \frac{6}{10} = 0.6$$

$$H(P) = -(0.4 \log_2 0.4) - (0.6 \log_2 0.6) \approx \mathbf{0.971}$$

#### Information Gain of Attribute A

**A = T (7 people):** has (+)4, (-)3

$$H(A_T) = -(4/7 \log_2 4/7) - (3/7 \log_2 3/7) \approx 0.985$$

**A = F (3 people):** has (+)0, (-)3 (Pure)

$$H(A_F) = -(0) - (1 \log_2 1) = 0$$

**Weighted Entropy:**

$$\frac{7}{10}(0.985) + \frac{3}{10}(0) = 0.6895$$

**Information Gain(A):**

$$0.971 - 0.6895 = \mathbf{0.2815}$$

#### Information Gain of Attribute B

**B = T (4 people):** has (+)3, (-)1

$$H(B_T) = -(0.75 \log_2 0.75) - (0.25 \log_2 0.25) \approx 0.811$$

**B = F (6 people):** has (+)1, (-)5

$$H(B_F) = -(1/6 \log_2 1/6) - (5/6 \log_2 5/6) \approx 0.650$$

**Weighted Entropy:**

$$\frac{4}{10}(0.811) + \frac{6}{10}(0.650) = 0.3244 + 0.39 = 0.7144$$

**Information Gain(B):**

$$0.971 - 0.7144 = \mathbf{0.2566}$$

#### Summary 5a

<Callout title="✅ Choose Attribute A" type="success">
Because Gain(A) = 0.2815 > Gain(B) = 0.2566
</Callout>

---

### 5b. Calculate Gain in Gini Index (Choose A or B?)

#### Gini Index Formula

$$\text{Gini}(S) = 1 - \sum p_i^2$$

#### Gini of Parent (P)

$$\text{Gini}(P) = 1 - [(0.4)^2 + (0.6)^2] = 1 - (0.16 + 0.36) = \mathbf{0.48}$$

#### Gini of Attribute A

**A = T:**

$$1 - [(4/7)^2 + (3/7)^2] = 1 - (0.327 + 0.184) \approx 0.489$$

**A = F:**

$$1 - [0^2 + 1^2] = 0$$

**Weighted Gini:**

$$\frac{7}{10}(0.489) + \frac{3}{10}(0) = \mathbf{0.3423}$$

**Gain Gini(A):**

$$0.48 - 0.3423 = \mathbf{0.1377}$$

#### Gini of Attribute B

**B = T:**

$$1 - [(0.75)^2 + (0.25)^2] = 1 - (0.5625 + 0.0625) = 0.375$$

**B = F:**

$$1 - [(1/6)^2 + (5/6)^2] = 1 - (0.028 + 0.694) \approx 0.278$$

**Weighted Gini:**

$$\frac{4}{10}(0.375) + \frac{6}{10}(0.278) = 0.15 + 0.1668 = \mathbf{0.3168}$$

**Gain Gini(B):**

$$0.48 - 0.3168 = \mathbf{0.1632}$$

#### Summary 5b

<Callout title="✅ Choose Attribute B" type="success">
Because Gain Gini(B) = 0.1632 > Gain Gini(A) = 0.1377
</Callout>

---

### 5c. Explanation - Can we choose different Attributes?

#### Answer

<Callout title="✅ Possible (Yes)" type="success">
As seen in this example (Info Gain chose A but Gini chose B)
</Callout>

#### Reason

**Information Gain (Entropy):**
- Tends to be biased towards Attributes that divide into the most "Pure" subgroups.
- Even if that group is small (e.g. A=F only has 3 people, but 100% pure, making Entropy drop drastically).

**Gini Index:**
- Tends to prefer divisions that result in "large and moderately pure" groups rather than small, highly pure groups.
- Gini will not drop as fast as Entropy when it encounters a small Pure node.

## Question 6: Gini Index of Node Splitting

||P|C1|C2|
|--|--|--|--|
|Class 0|7|3|4|
|Class 1|3|0|3|

### Data

- **Parent (P):** Class 0 = 7, Class 1 = 3 (Total 10)
- **Child 1 (C1):** Class 0 = 3, Class 1 = 0 (Total 3) → Pure
- **Child 2 (C2):** Class 0 = 4, Class 1 = 3 (Total 7)

---

### 6a. Calculate Gini index of node P

$$\text{Gini}(P) = 1 - \left[ \left(\frac{7}{10}\right)^2 + \left(\frac{3}{10}\right)^2 \right]$$

$$\text{Gini}(P) = 1 - [0.49 + 0.09] = 1 - 0.58 = \mathbf{0.42}$$

---

### 6b. Calculate Weighted Gini index & Decision

#### Gini of Child 1 (C1)

This group only has Class 0 (Pure).

$$\text{Gini}(C1) = 1 - [(3/3)^2 + (0/3)^2] = 1 - 1 = \mathbf{0}$$

#### Gini of Child 2 (C2)

$$\text{Gini}(C2) = 1 - [(4/7)^2 + (3/7)^2] = 1 - [0.3265 + 0.1837] \approx 1 - 0.51 = \mathbf{0.49}$$

#### Weighted Gini

$$\text{Weighted Gini} = \frac{3}{10} \times \text{Gini}(C1) + \frac{7}{10} \times \text{Gini}(C2)$$

$$= (0.3 \times 0) + (0.7 \times 0.49) = \mathbf{0.343}$$

#### Decision Summary

<Callout title="📊 Comparison Result" type="info">
- Old Gini: 0.42
- New Gini (Weighted): 0.343
- Reduced value (Gain): 0.42 - 0.343 = **0.077**
</Callout>

<Callout title="✅ Should Consider (Yes)" type="success">
Because Gini value decreased, it means the data purity increased (Impurity decreased), especially Node C1 which split out to be 100% pure.
</Callout>
