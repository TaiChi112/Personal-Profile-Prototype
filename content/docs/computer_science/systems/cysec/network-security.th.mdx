# สรุปความปลอดภัยเครือข่าย (Network Security Cheat Sheet)

ภาพรวมแนวคิดหลักด้านความปลอดภัยของเครือข่ายอย่างย่อ

## ไฟร์วอลล์ (Firewalls)
*   **คำจำกัดความ:** อุปกรณ์รักษาความปลอดภัยเครือข่ายที่ตรวจสอบและกรองทราฟฟิกเครือข่ายขาเข้าและขาออกตามนโยบายความปลอดภัยที่กำหนดไว้
*   **ประเภท:**
    *   **Packet Filtering:** ตรวจสอบแพ็กเก็ตและอนุญาต/บล็อกตาม IP, พอร์ต, หรือโปรโตคอล
    *   **Stateful Inspection:** ติดตามสถานะและลักษณะของการเชื่อมต่อเครือข่าย
    *   **Proxy Firewalls:** ทำหน้าที่เป็นตัวกลางสำหรับคำขอจากไคลเอนต์ที่ต้องการทรัพยากร
    *   **Next-Generation Firewall (NGFW):** รวมเทคโนโลยีไฟร์วอลล์แบบดั้งเดิมเข้ากับฟังก์ชันเพิ่มเติม เช่น การตรวจสอบการรับส่งข้อมูลที่เข้ารหัสและระบบป้องกันการบุกรุก (IPS)

## DDoS (Distributed Denial of Service)
*   **คำจำกัดความ:** ความพยายามที่เป็นอันตรายในการขัดจังหวะทราฟฟิกปกติของเซิร์ฟเวอร์ บริการ หรือเครือข่ายเป้าหมาย โดยการส่งทราฟฟิกอินเทอร์เน็ตจำนวนมหาศาลเพื่อทำให้เป้าหมายหรือโครงสร้างพื้นฐานโดยรอบทำงานไม่ทัน
*   **ประเภทการโจมตี:**
    *   **Volumetric:** โจมตีแบนด์วิดท์ (เช่น UDP floods)
    *   **Protocol:** ใช้ทรัพยากรเซิร์ฟเวอร์จริงหรืออุปกรณ์สื่อสารระดับกลาง (เช่น SYN floods)
    *   **Application Layer:** กำหนดเป้าหมายแอปพลิเคชันบนเว็บ (เช่น HTTP floods)
*   **การบรรเทาผลกระทบ:** การจำกัดอัตรา (Rate limiting), การกำหนดเส้นทางเครือข่ายแบบ Anycast, การกรองชื่อเสียงของ IP, และศูนย์คัดกรองข้อมูล (Scrubbing centers)

## MitM (Man-in-the-Middle)
*   **คำจำกัดความ:** การโจมตีที่ผู้กระทำผิดลักลอบถ่ายทอดและอาจเปลี่ยนแปลงการสื่อสารระหว่างสองฝ่ายที่เชื่อว่ากำลังสื่อสารกันโดยตรง
*   **วิธีการ:** ARP spoofing, DNS spoofing, การปล้นเซสชัน (Session hijacking), การแอบฟัง Wi-Fi
*   **การป้องกัน:**
    *   ใช้การเข้ารหัสที่รัดกุม (TLS/SSL)
    *   ใช้งาน HTTP Strict Transport Security (HSTS)
    *   ใช้เครือข่ายส่วนตัวเสมือน (VPN)
    *   ใช้งาน Certificate pinning ในแอปพลิเคชัน

## WAF (Web Application Firewall)
*   **คำจำกัดความ:** ไฟร์วอลล์แอปพลิเคชันรูปแบบเฉพาะที่ทำหน้าที่กรอง ตรวจสอบ และบล็อกทราฟฟิก HTTP ที่เข้าและออกจากบริการเว็บ
*   **วัตถุประสงค์:** ปกป้องเว็บแอปพลิเคชันจากการเจาะระบบแบบ Zero-day, มัลแวร์, การแอบอ้าง, และช่องโหว่ที่เป็นที่รู้จัก (เช่น OWASP Top 10)
*   **การป้องกันหลัก:** Cross-Site Scripting (XSS), SQL Injection (SQLi), การรวมไฟล์ผิดกฎหมาย, และ Cross-site forgery
*   **การทำงาน:** ทำงานที่ Layer 7 ของโมเดล OSI โดยสามารถปรับแต่งนโยบายให้เหมาะกับความต้องการเฉพาะของเว็บแอปพลิเคชันได้
