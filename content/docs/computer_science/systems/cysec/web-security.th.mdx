# สรุปความปลอดภัยเว็บ (Web Security)

## แนวคิดหลัก
* **OWASP Top 10**: เอกสารมาตรฐานสำหรับนักพัฒนาด้านความปลอดภัยของแอปพลิเคชันเว็บที่แสดงถึงความเสี่ยงด้านความปลอดภัยที่สำคัญที่สุด
* **SQL Injection (SQLi)**: เกิดขึ้นเมื่อมีการแทรกคำสั่ง SQL ที่เป็นอันตรายลงในฟิลด์ป้อนข้อมูลเพื่อประมวลผล อาจนำไปสู่การรั่วไหล การแก้ไข หรือการทำลายข้อมูล ควรป้องกันด้วย Parameterized Queries
* **Cross-Site Scripting (XSS)**: ผู้โจมตีแทรกสคริปต์ที่เป็นอันตรายลงในโค้ดของแอปพลิเคชันหรือเว็บไซต์ที่เชื่อถือได้ มักใช้เพื่อขโมยคุกกี้เซสชันหรือโทเค็น
  * *Stored XSS*: โค้ดอันตรายจะถูกเก็บไว้อย่างถาวรบนเซิร์ฟเวอร์เป้าหมาย
  * *Reflected XSS*: โค้ดอันตรายจะถูกส่งกลับทันทีโดยเว็บแอปพลิเคชัน
  * *DOM-based XSS*: โค้ดอันตรายจะถูกทำงานเป็นผลมาจากการแก้ไขสภาพแวดล้อม DOM ในเบราว์เซอร์ของเหยื่อ
* **Cross-Site Request Forgery (CSRF)**: บังคับให้ผู้ใช้ดำเนินการที่ไม่ต้องการในเว็บแอปพลิเคชันที่พวกเขาได้ตรวจสอบสิทธิ์ในปัจจุบัน ควรป้องกันด้วย Anti-CSRF Token
