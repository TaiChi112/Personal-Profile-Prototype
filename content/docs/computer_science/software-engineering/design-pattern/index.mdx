# Design Patterns

Design Patterns คือรูปแบบการแก้ปัญหาที่เกิดขึ้นซ้ำๆ ในการทำ Software Design ซึ่งสามารถนำมาประยุกต์ใช้เพื่อปรับปรุง Code Architecture ให้มีความยืดหยุ่นและง่ายต่อการดูแลรักษา
