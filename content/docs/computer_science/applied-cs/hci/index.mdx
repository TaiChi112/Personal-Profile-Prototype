## UX/UI Principles
User Experience (UX) and User Interface (UI) design focuses on enhancing Usability so that Users can achieve their goals efficiently.
- **Consistency**: The use of consistent Design Patterns and Components to reduce Cognitive Load.
- **Feedback**: The system must display its status and respond to User Actions clearly and promptly.
- **Affordance**: Designing Components to clearly indicate their natural usage.

## Nielsen's Heuristics
10 Usability principles for Interaction Design inspection.
1. **Visibility of system status**: The system should keep Users informed about its current status at all times.
2. **Match between system and the real world**: Use terminology and concepts that match the real world.
3. **User control and freedom**: Provide a way for Users to cancel or quickly exit an unwanted state.
4. **Consistency and standards**: Follow standards and conventions that Users are familiar with.
5. **Error prevention**: Design to prevent errors before they occur.
6. **Recognition rather than recall**: Clearly display options or information to reduce memory load.
7. **Flexibility and efficiency of use**: Provide Shortcuts for Expert Users.
8. **Aesthetic and minimalist design**: Present only the information necessary for the current Task.
9. **Help users recognize, diagnose, and recover from errors**: Error messages must be clear and propose solutions.
10. **Help and documentation**: Provide helpful documentation that is easy to access and relevant to what the User is currently doing.

## Accessibility
Designing systems to support all User groups, including those with Disabilities.
- **Color Contrast**: Use an appropriate Contrast Ratio for Text and Background for reading clarity.
- **Screen Reader Support**: The use of Semantic HTML and ARIA Attributes for visually impaired Users.
- **Keyboard Navigation**: Support the use of all system functions via Keyboard without relying on a mouse.
