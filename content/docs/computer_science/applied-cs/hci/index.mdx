## UX/UI Principles
การออกแบบ User Experience (UX) และ User Interface (UI) มุ่งเน้นการยกระดับ Usability เพื่อให้ User สามารถบรรลุเป้าหมายได้อย่างมีประสิทธิภาพ
- **Consistency**: การใช้ Design Pattern และ Component ที่สอดคล้องกัน เพื่อลด Cognitive Load
- **Feedback**: ระบบต้องแสดงสถานะและการตอบสนองต่อ Action ของ User อย่างชัดเจนและทันท่วงที
- **Affordance**: การออกแบบ Component ให้สื่อถึงวิธีการใช้งานอย่างชัดเจนตามธรรมชาติ

## Nielsen's Heuristics
หลักการตรวจสอบ Usability 10 ประการสำหรับการออกแบบ Interaction Design
1. **Visibility of system status**: ระบบควรแจ้งสถานะปัจจุบันให้ User ทราบตลอดเวลา
2. **Match between system and the real world**: ใช้คำศัพท์และแนวคิดที่ตรงกับโลกแห่งความเป็นจริง
3. **User control and freedom**: มีช่องทางให้ User ยกเลิกหรือออกจากสถานะที่ไม่ต้องการได้อย่างรวดเร็ว
4. **Consistency and standards**: ปฏิบัติตามมาตรฐานและแบบแผนที่ User คุ้นเคย
5. **Error prevention**: ออกแบบเพื่อป้องกันความผิดพลาดก่อนที่จะเกิดขึ้น
6. **Recognition rather than recall**: แสดงตัวเลือกหรือข้อมูลให้เห็นชัดเจนเพื่อลดภาระความจำ
7. **Flexibility and efficiency of use**: มีช่องทางลัด (Shortcuts) สำหรับ Expert User
8. **Aesthetic and minimalist design**: นำเสนอเฉพาะข้อมูลที่จำเป็นต่อ Task ปัจจุบัน
9. **Help users recognize, diagnose, and recover from errors**: ข้อความแจ้งข้อผิดพลาดต้องชัดเจนและเสนอวิธีแก้ไข
10. **Help and documentation**: มีคู่มือช่วยเหลือที่เข้าถึงง่ายและตรงกับสิ่งที่ User กำลังทำ

## Accessibility
การออกแบบระบบเพื่อให้รองรับ User ทุกกลุ่ม รวมถึงผู้ที่มีความบกพร่อง (Disabilities)
- **Color Contrast**: ใช้ Contrast Ratio ที่เหมาะสมสำหรับ Text และ Background เพื่อความชัดเจนในการอ่าน
- **Screen Reader Support**: การใช้ Semantic HTML และ ARIA Attributes สำหรับ User ที่มีความบกพร่องทางสายตา
- **Keyboard Navigation**: รองรับการใช้งานระบบทุกฟังก์ชันผ่าน Keyboard โดยไม่ต้องพึ่งพาเมาส์
