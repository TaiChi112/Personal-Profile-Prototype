# Common Problems in Digital Image Processing (DIP)

Here are common problems in Image Processing, along with their names and the techniques used to solve them. This will help you practice your Digital Image Processing (DIP) knowledge completely, from Preprocessing to Processing to Postprocessing.

## Image Quality Issues

### 1. Noise
   - **Description**: Unwanted random variations in brightness or color information in images.
   - **Techniques**: Median Filtering, Gaussian Smoothing, Bilateral Filtering, Non-Local Means
   - **Problem**: Images contain noise, making details unclear, such as images from mobile cameras in the dark or old scanned photos.

| **Noise Type**        | **Image Characteristics**                | **Solution Techniques**                |
| ------

----------------- | ---------------------------- | ------------------------------ |
| **Gaussian Noise**      | Randomly distributed noise throughout the image | Gaussian Filter, Wiener Filter |
| **Salt & Pepper Noise** | Black and white dots scattered in patches   | Median Filter                  |
| **Speckle Noise**       | Found in Ultrasound images           | Adaptive Filtering             |
| **Poisson Noise**       | Caused by photon counting in images      | Variance Stabilizing Transform |

**Practice**:
```python
# Example Code for reducing noise with OpenCV
import cv2
import numpy as np
from skimage.metrics import peak_signal_noise_ratio as psnr

# Read image
img = cv2.imread('noisy_image.jpg')

# Reduce Gaussian Noise
gaussian_blur = cv2.GaussianBlur(img, (5, 5), 0)

# Reduce Salt & Pepper Noise
median_blur = cv2.medianBlur(img, 5)

# Advanced noise reduction with Non-Local Means
nlm_blur = cv2.fastNlMeansDenoisingColored(img, None, 10, 10, 7, 21)

# Compare quality
print("PSNR Gaussian:", psnr(img, gaussian_blur))
print("PSNR Median:", psnr(img, median_blur))
print("PSNR NLM:", psnr(img, nlm_blur))
```

### 2. Blurring (Out of Focus)
   - **Description**: Loss of sharpness in images, often due to camera shake or out-of-focus capture.
   - **Techniques**: Deconvolution, Wiener Filter, Blind Deconvolution, Richardson-Lucy Algorithm
   - **Problem**: Blurry images from camera movement or incorrect focus, such as shaky camera shots or out-of-focus images.

| **Cause**              | **Solution Techniques**                              |
| ------

----------------- | -------------------------------------------- |
| Motion Blur | Wiener Filter, Lucy-Richardson Deconvolution |
| Out of Focus            | Laplacian Sharpening, Unsharp Masking        |
| Camera Shake            | Blind Deconvolution                          |

**Practice**:
```python
# Example Code for fixing blurry images
import cv2
import numpy as np

# Read image
img = cv2.imread('blurry_image.jpg')

# 1. Unsharp Masking - Increase sharpness
gaussian = cv2.GaussianBlur(img, (5, 5), 0)
unsharp_masked = cv2.addWeighted(img, 1.5, gaussian, -0.5, 0)

# 2. Create artificial Motion Blur (for testing)
kernel_size = 15
kernel_motion_blur = np.zeros((kernel_size, kernel_size))
kernel_motion_blur[int((kernel_size-1)/2), :] = np.ones(kernel_size)
kernel_motion_blur = kernel_motion_blur / kernel_size
motion_blur = cv2.filter2D(img, -1, kernel_motion_blur)

# Display images
cv2.imshow("Original", img)
cv2.imshow("Enhanced (Unsharp Masked)", unsharp_masked)
cv2.waitKey(0)
```

### 3. Low Contrast
   - **Description**: Images with poor contrast, making it difficult to distinguish between different regions.
   - **Techniques**: Histogram Equalization, Contrast Limited Adaptive Histogram Equalization (CLAHE), Gamma Correction
   - **Problem**: Images have low contrast, appear dull, colors are not clear. Often caused by insufficient lighting or backlit photos.

| **Solution Techniques**                                          | **Description**                         |
| ------

-------------------------------------------------- | ------------------------------------ |
| Histogram Equalization                                   | Redistributes brightness across the entire image       |
| CLAHE (Contrast Limited Adaptive Histogram Equalization) | Suitable for medical images            |
| Gamma Correction                                         | Used for overexposed or underexposed images |

**Practice**:
```python
# Example Code for contrast adjustment
import cv2
import numpy as np

# Read image
img = cv2.imread('low_contrast.jpg', 0)  # Read as grayscale

# 1. Histogram Equalization - Suitable for general images
hist_eq = cv2.equalizeHist(img)

# 2. CLAHE - Suitable for medical images and images with complex details
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
clahe_img = clahe.apply(img)

# 3. Gamma Correction - Brightness adjustment
gamma = 1.5
gamma_corrected = np.array(255 * (img / 255) ** gamma, dtype='uint8')

# Display images
cv2.imshow("Original", img)
cv2.imshow("Histogram Equalized", hist_eq)
cv2.imshow("CLAHE", clahe_img)
cv2.waitKey(0)
```

## Feature and Edge Analysis

### 4. Edge Detection (Unclear image edges)
    - **Description**: Difficulty in accurately detecting edges in images due to noise or low contrast.
    - **Techniques**: Canny Edge Detector, Sobel Operator, Prewitt Operator, Laplacian of Gaussian (LoG)
    - **Problem**: Object edges in the image are unclear, or edge detection yields poor results. For example, images with a lot of noise or objects with low contrast edges.

| **Solution Techniques**             | **Suitable For**            |
| ------

--------------------- | -------------------------- |
| Sobel / Prewitt Filter      | Basic edges                 |
| Canny Edge Detection        | Sharp edges and noise reduction |
| Laplacian of Gaussian (LoG) | Images with high details      |

**Practice**:
```python
# Example Code for image edge detection
import cv2
import numpy as np

# Read image
img = cv2.imread('edge_example.jpg', 0)  # Read as grayscale

# Reduce noise before edge detection (very important)
img = cv2.GaussianBlur(img, (5, 5), 0)

# 1. Sobel Edge Detection
sobelx = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
sobely = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)
sobel_combined = cv2.magnitude(sobelx, sobely)
sobel_combined = np.uint8(sobel_combined)

# 2. Canny Edge Detection
canny_edges = cv2.Canny(img, 100, 200)  # Adjust threshold values as appropriate

# 3. Laplacian Edge Detection
laplacian = cv2.Laplacian(img, cv2.CV_64F)
laplacian = np.uint8(np.absolute(laplacian))

# Compare
cv2.imshow("Original", img)
cv2.imshow("Sobel", sobel_combined)
cv2.imshow("Canny", canny_edges)
cv2.imshow("Laplacian", laplacian)
cv2.waitKey(0)
```

### 5. Distortion
    - **Description**: Geometric distortions in images caused by lens imperfections or perspective issues.
    - **Techniques**: Geometric Transformations, Camera Calibration, Lens Distortion Correction
    - **Problem**: Images from camera lenses often have curvature, such as Fish-eye, or wide-angle shots that make objects appear distorted.

| **Distortion Type**                | **Solution Techniques**                |
| ------

------------------------------ | ------------------------------ |
| Barrel Distortion (Edges bulge out)     | Camera Calibration + Remapping |
| Pincushion Distortion (Edges shrink in) | Camera Calibration             |

**Practice**:
```python
# Example Code for distortion correction
import cv2
import numpy as np

# Read distorted image
img = cv2.imread('distorted_image.jpg')

# Create camera matrix and distortion coefficients (obtained from camera calibration)
# Example parameters (should use actual calibrated values)
camera_matrix = np.array([[800, 0, img.shape[1]/2], 
                          [0, 800, img.shape[0]/2], 
                          [0, 0, 1]])
dist_coeffs = np.array([-0.2, 0.1, 0, 0])  # k1, k2, p1, p2

# Correct distortion
undistorted_img = cv2.undistort(img, camera_matrix, dist_coeffs)

# Display results
cv2.imshow("Original (Distorted)", img)
cv2.imshow("Corrected", undistorted_img)
cv2.waitKey(0)

# If you want to calibrate a camera, you should use a set of multiple chessboard pattern images
```

### 6. Thresholding & Segmentation
    - **Description**: Difficulty in segmenting objects from the background due to shadows or uneven lighting.
    - **Techniques**: Adaptive Thresholding, Otsu's Binarization, Watershed Algorithm, Grabcut
    - **Problem**: Need to segment objects from the background, but there are shadows or uneven lighting, making it difficult to separate objects from the background.

| **Solution Techniques**         | **Use Case**        |
| ------

----------------- | --------------------- |
| Global Threshold (Otsu) | Evenly lit images     |
| Adaptive Threshold      | Unevenly lit images  |
| Watershed Segmentation  | Separate overlapping objects |
| GrabCut                 | Separate complex objects       |

**Practice**:
```python
# Example Code for Segmentation
import cv2
import numpy as np

# Read image
img = cv2.imread('object.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 1. Global Thresholding (Otsu)
ret, thresh_otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# 2. Adaptive Thresholding
adaptive_thresh = cv2.adaptiveThreshold(gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                        cv2.THRESH_BINARY, 11, 2)

# 3. Watershed Segmentation (Basic example)
# Create markers from foreground and background
ret, markers = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
markers = np.int32(markers)
watershed_result = img.copy()
cv2.watershed(img, markers)
watershed_result[markers == -1] = [0, 0, 255]  # Draw red borders

# Display results
cv2.imshow("Original", img)
cv2.imshow("Otsu Thresholding", thresh_otsu)
cv2.imshow("Adaptive Thresholding", adaptive_thresh)
cv2.imshow("Watershed", watershed_result)
cv2.waitKey(0)
```

## Lighting and Color Challenges

### 7. Illumination Variations
   - **Description**: Uneven lighting conditions causing parts of the image to be too bright or too dark.
   - **Techniques**: Histogram Equalization, Adaptive Histogram Equalization (CLAHE), Gamma Correction, Retinex Algorithms
   - **Problem**: Images have uneven lighting, such as indoor photos with insufficient lighting coverage or outdoor photos with dark shadows.

| **Problem Type**         | **Solution Techniques**                        |
| ------

----------------- | -------------------------------------- |
| Uneven Lighting         | Histogram Equalization, CLAHE         |
| Shadows                 | Shadow Removal Techniques              |
| Highlights               | Highlight Recovery Techniques          |
| Low Light               | Multi-Scale Retinex                    |

**Practice**:
```python
# Example Code for fixing uneven lighting
import cv2
import numpy as np

# Read image
img = cv2.imread('uneven_light.jpg')

# Convert to LAB color space (L=Lightness, A=Green-Red, B=Blue-Yellow)
lab = cv2.cvtColor(img, cv2.COLOR_BGR2LAB)
l, a, b = cv2.split(lab)

# Correct only the L (Lightness) channel with CLAHE
clahe = cv2.createCLAHE(clipLimit=3.0, tileGridSize=(8, 8))
cl = clahe.apply(l)

# Merge color channels back
updated_lab = cv2.merge((cl, a, b))

# Convert back to BGR
corrected_img = cv2.cvtColor(updated_lab, cv2.COLOR_LAB2BGR)

# Display results
cv2.imshow("Original", img)
cv2.imshow("Corrected", corrected_img)
cv2.waitKey(0)
```

### 8. Color Issues
    - **Description**: Problems related to color accuracy and consistency in images.
    - **Techniques**: Color Correction, White Balance Adjustment, Color Space Transformation
    - **Problem**: Distorted colors from lighting or camera, causing colors seen in the image to not match reality.

| **Problem**          | **Solution Techniques**                              |
| ------

------------ | -------------------------------------------- |
| Incorrect White Balance  | Gray World Algorithm                         |
| Dull Colors          | HSV Color Enhancement                        |
| Want to emphasize specific color | Masking + Color Space Conversion (BGR to HSV) |
| Color Cast         | Color Transfer, Color Grading                |

**Practice**:
```python
# Example Code for color issue correction
import cv2
import numpy as np

# Read image
img = cv2.imread('color_problem.jpg')

# 1. Gray World Algorithm (White Balance)
def gray_world(img):
    # Split color channels
    b, g, r = cv2.split(img)
    
    # Find mean of each color channel
    r_avg = np.mean(r)
    g_avg = np.mean(g)
    b_avg = np.mean(b)
    
    # Find overall mean
    avg = (r_avg + g_avg + b_avg) / 3
    
    # Balance colors
    r = r * (avg / r_avg)
    g = g * (avg / g_avg)
    b = b * (avg / b_avg)
    
    # Ensure values do not exceed 255
    r = np.clip(r, 0, 255).astype(np.uint8)
    g = np.clip(g, 0, 255).astype(np.uint8)
    b = np.clip(b, 0, 255).astype(np.uint8)
    
    # Merge color channels back
    return cv2.merge([b, g, r])

# 2. Extract specific color (e.g., Red)
def extract_red(img):
    # Convert to HSV
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
    
    # Define red color range (HSV)
    lower_red1 = np.array([0, 100, 100])
    upper_red1 = np.array([10, 255, 255])
    lower_red2 = np.array([160, 100, 100])
    upper_red2 = np.array([179, 255, 255])
    
    # Create mask
    mask1 = cv2.inRange(hsv, lower_red1, upper_red1)
    mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
    mask = mask1 + mask2
    
    # Multiply mask with original image
    result = cv2.bitwise_and(img, img, mask=mask)
    return result

# Process
white_balanced = gray_world(img)
red_only = extract_red(img)

# Display results
cv2.imshow("Original", img)
cv2.imshow("White Balanced", white_balanced)
cv2.imshow("Red Only", red_only)
cv2.waitKey(0)
```

### 9. Color Distortion
   - **Description**: Inaccurate color representation due to lighting conditions or camera settings.
   - **Techniques**: Color Correction, White Balance Adjustment, Color Space Transformation, Color Transfer
   - **Problem**: Colors in the image do not match reality, such as photos with color distortion from fluorescent lights or photos taken in low light.

| **Problem Type**         | **Solution Techniques**                        |
| ------

----------------- | -------------------------------------- |
| Color Cast              | White Balance Adjustment               |
| Faded Colors            | Color Correction                       |
| Low Saturation          | Saturation Adjustment                  |
| Mixed Lighting Sources  | Color Temperature Correction           |

**Practice**:
```python
# Example Code for color correction with LAB Color Space
import cv2
import numpy as np

# Read image
img = cv2.imread('color_distorted.jpg')

# Convert to LAB color space (suitable for color correction)
lab = cv2.cvtColor(img, cv2.COLOR_BGR2LAB)
l, a, b = cv2.split(lab)

# Adjust A channel (Green-Red axis)
a = cv2.add(a, 5)  # Adjust to be more red

# Adjust B channel (Blue-Yellow axis)
b = cv2.add(b, -5)  # Adjust to be more blue

# Merge color channels back
corrected_lab = cv2.merge((l, a, b))
corrected_img = cv2.cvtColor(corrected_lab, cv2.COLOR_LAB2BGR)

# Adjust Color Saturation
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
h, s, v = cv2.split(hsv)
s = cv2.multiply(s, 1.3)  # Increase saturation by 30%
s = np.clip(s, 0, 255).astype(np.uint8)
saturated_hsv = cv2.merge([h, s, v])
saturated_img = cv2.cvtColor(saturated_hsv, cv2.COLOR_HSV2BGR)

# Display results
cv2.imshow("Original", img)
cv2.imshow("Color Corrected (LAB)", corrected_img)
cv2.imshow("Saturation Enhanced", saturated_img)
cv2.waitKey(0)
```

## Advanced Challenges

### 10. Compression Artifacts
   - **Description**: Loss of image quality due to lossy compression techniques.
   - **Techniques**: Artifact Reduction Filters, Super-Resolution Techniques, Deep Learning Methods
   - **Problem**: Images contain noise or distortion from compression, such as heavily compressed JPEG images causing blockiness or jagged edges.

| **Problem Type**         | **Solution Techniques**                        |
| ------

----------------- | -------------------------------------- |
| Blocking Artifacts      | Block Matching, Inpainting            |
| Blurring                | Deblurring Techniques                 |
| Color Banding           | Dithering, Color Space Transformation |
| JPEG Compression        | JPEG Artifact Removal Filters         |

**Practice**:
```python
# Example Code for reducing Compression Artifacts
import cv2
import numpy as np

# Read image
img = cv2.imread('compressed_image.jpg')

# 1. Use Non-local Means Denoising (Suitable for Compression Artifacts)
denoised = cv2.fastNlMeansDenoisingColored(img, None, 10, 10, 7, 21)

# 2. Use Bilateral Filter (Preserves edges but reduces noise)
bilateral = cv2.bilateralFilter(img, 9, 75, 75)

# 3. Increase sharpness after reducing artifacts
kernel = np.array([[-1, -1, -1],
                   [-1, 9, -1],
                   [-1, -1, -1]])
sharpened = cv2.filter2D(denoised, -1, kernel)

# Display results
cv2.imshow("Original (Compressed)", img)
cv2.imshow("Denoised (NLM)", denoised)
cv2.imshow("Bilateral Filter", bilateral)
cv2.imshow("Sharpened After Denoising", sharpened)
cv2.waitKey(0)
```

### 11. Image Resolution Enhancement
   - **Description**: Need to improve the resolution of low-quality images.
   - **Techniques**: Super-Resolution, Deep Learning (SRGAN, ESRGAN), Interpolation
   - **Problem**: Images have low resolution, need to increase resolution without blurring the image or distorting details.

| **Technique**                  | **Description**                                    |
| ------

--------------------- | ---------------------------------------------- |
| Bicubic Interpolation       | Traditional method, simple but results are not very good               |
| SRGAN                       | Uses GAN to increase resolution efficiently |
| ESRGAN                      | Improved from SRGAN for better results                   |
| Real-ESRGAN                 | Latest version, works well with real images             |

**Note**:
- PSNR (Peak Signal-to-Noise Ratio) and SSIM (Structural Similarity Index) are standards used to measure image quality after processing.
- Try using OpenCV or scikit-image to experiment with these techniques to comprehensively improve your Digital Image Processing (DIP) skills and understanding.

## Practical Workflow

**Training Roadmap**

1. Start with Preprocessing
   - Noise Removal to Histogram Equalization to Sharpening
2. Processing
   - Edge Detection to Segmentation to Morphological Operations
3. Postprocessing
   - Object Tracking to Feature Extraction to Classification

**Example Problem**
- Have old document photos taken with a mobile phone: Blurry + noisy + low contrast

**Correction Steps:**
1. Noise Removal: Median Filter
2. Sharpening: Unsharp Mask
3. Contrast Enhancement: CLAHE
4. Thresholding: Adaptive Threshold

```python
# Example Complete Pipeline for Document Image Correction
import cv2
import numpy as np

# Read document image
document = cv2.imread('document_image.jpg')

# 1. Convert to grayscale
gray = cv2.cvtColor(document, cv2.COLOR_BGR2GRAY)

# 2. Reduce noise with Median Filter
denoised = cv2.medianBlur(gray, 5)

# 3. Increase sharpness with Unsharp Masking
gaussian = cv2.GaussianBlur(denoised, (0, 0), 3)
unsharp_masked = cv2.addWeighted(denoised, 1.5, gaussian, -0.5, 0)

# 4. Enhance contrast with CLAHE
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
enhanced = clahe.apply(unsharp_masked)

# 5. Apply Thresholding to separate text from background
adaptive_thresh = cv2.adaptiveThreshold(enhanced, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
                                        cv2.THRESH_BINARY, 11, 2)

# Display results at each step
cv2.imshow("Original", document)
cv2.imshow("Denoised", denoised)
cv2.imshow("Contrast Enhanced", enhanced)
cv2.imshow("Final Document", adaptive_thresh)
cv2.waitKey(0)
```
