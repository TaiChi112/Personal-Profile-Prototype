This guide summarizes steps and Best Practices for Contributing to the Documentation system.

## Best Practices

When writing Documentation, please follow these guidelines:
- Use TH Core Hybrid EN language (Thai sentence structure with English Technical terms).
- Consistently maintain a Professional tone.
- Emojis are strictly prohibited in content and Headings.

## Markdown Standards

Document formatting must follow Markdown standards:
- Use Headings in correct hierarchical order (H2, H3, H4).
- Use Code blocks with Programming language specified for Code snippets.
- Avoid using unnecessary HTML tags. It is recommended to use the provided MDX components.

## Git Workflow

Workflow for Version control:
1. Create a new Branch from the Main branch for each Feature or Fix.
2. Commit changes with clear and meaningful Commit messages.
3. Check the display Locally to confirm correctness.
4. Create a Pull Request (PR) to receive Review before Merging into the Main branch.
