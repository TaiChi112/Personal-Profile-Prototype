# 🔗 Relations & Functions (สรุปด่วน)

## 1. Relations (ความสัมพันธ์)
การเชื่อมโยงข้อมูลจากเซตหนึ่งไปยังอีกเซตหนึ่ง (หรือเซตตัวเอง)
- **Reflexive:** ทุกตัวมีความสัมพันธ์กับตัวเอง (`aRa`)
- **Symmetric:** ถ้า `a` สัมพันธ์กับ `b` แล้ว `b` ต้องสัมพันธ์กับ `a` (`aRb -> bRa`)
- **Transitive:** ถ้า `a` สัมพันธ์กับ `b` และ `b` สัมพันธ์กับ `c` แล้ว `a` ต้องสัมพันธ์กับ `c` (`aRb ∧ bRc -> aRc`)
- **Equivalence Relation:** เป็นความสัมพันธ์ที่มีครบทั้ง 3 ข้อข้างต้น

## 2. Functions (ฟังก์ชัน)
ความสัมพันธ์พิเศษที่ข้อมูลต้นทาง (Domain) 1 ตัว ส่งค่าไปยังปลายทาง (Codomain) ได้เพียง 1 ค่าเท่านั้น
- **Injective (One-to-One):** ปลายทางไม่รับลูกศรซ้ำซ้อนจากต้นทาง
- **Surjective (Onto):** ปลายทางทุกตัวถูกจับคู่หมด ไม่มีตัวว่าง
- **Bijective (One-to-One and Onto):** เป็นทั้ง Injective และ Surjective (จับคู่แบบ 1:1 เป๊ะๆ สามารถหา Inverse Function ได้)
- **ประยุกต์ใช้:** Cryptography (การเข้ารหัส, Hash function) และการแปลงข้อมูลภาพ
