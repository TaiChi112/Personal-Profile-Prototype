# Logic & Sets (สรุปด่วน)

## 1. Propositional Logic (ตรรกศาสตร์)
ตรรกศาสตร์คือการให้เหตุผลเพื่อหาความจริง (True/False) ใช้มากในเงื่อนไข `if-else`
- **Proposition (ประพจน์):** ประโยคที่บอกได้แน่ชัดว่าเป็นจริงหรือเท็จ (เช่น "1+1=2" เป็นจริง, แต่ "x+1=2" ไม่ใช่ประพจน์เพราะไม่รู้ค่า x)
- **Operators:**
  - `AND (∧)`: จริงเมื่อจริงทั้งคู่
  - `OR (∨)`: จริงเมื่อมีอย่างน้อยหนึ่งจริง
  - `NOT (¬)`: สลับค่าความจริง
  - `XOR (⊕)`: จริงเมื่อค่าต่างกัน
  - `Implies (→)`: "ถ้า...แล้ว..." เป็นเท็จกรณีเดียวคือ "หน้าจริง หลังเท็จ" (T → F = F)

## 2. Set Theory (ทฤษฎีเซต)
พื้นฐานของการรวมกลุ่มข้อมูล และเป็นรากฐานของ Relational Database (SQL)
- **Set (เซต):** กลุ่มของข้อมูลที่ไม่ซ้ำกัน (เช่น `A = {1, 2, 3}`)
- **Operations:**
  - `Union (A ∪ B)`: รวมทุกตัวของ A และ B
  - `Intersection (A ∩ B)`: เอาเฉพาะตัวที่ซ้ำกันของ A และ B (หลักการเดียวกับ `INNER JOIN`)
  - `Difference (A \ B)`: เอาตัวที่อยู่ใน A แต่ไม่อยู่ใน B
  - `Subset (A ⊆ B)`: ทุกตัวใน A ต้องอยู่ใน B
