# Theory of Computation (TOC)

Theory of Computation คือสาขาหัวใจหลักของ Computer Science ที่มุ่งเน้นการศึกษาว่า **ปัญหาใดบ้างที่ Computer สามารถแก้ได้ (Computability)** และ **ต้องใช้ Resource มากแค่ไหนในการแก้ (Complexity)** โดยใช้ Mathematics และ Logic ในการสร้าง Model จำลองการทำงาน
