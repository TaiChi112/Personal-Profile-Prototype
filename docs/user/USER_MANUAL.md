# User Manual & FAQ

**Welcome to the Personal Profile Prototype (taichi112.works)!**  
This document serves as a quick guide on how to navigate and utilize the features available on this platform.

---

## 1. Navigating the Portfolio

The main website operates as a blazing-fast Single Page Application (SPA).
- **Navigation Bar:** Use the top navigation menu (or bottom bar on mobile) to switch between different sections such as **Home**, **Projects**, **Resume**, and **Contact**.
- **Dark Mode:** Click the Moon/Sun icon in the navigation bar to toggle between Light and Dark themes according to your preference.
- **Command Palette:** (If enabled) Press `Cmd + K` (Mac) or `Ctrl + K` (Windows) to open the quick search menu.

## 2. Exploring Technical Documentation

The platform hosts an extensive library of technical notes and documentation.
- **Accessing Docs:** Click the "Docs" tab in the navigation bar. You will be redirected to the Documentation Portal.
- **Languages (i18n):** Some documentation supports multiple languages (e.g., English and Thai). Look for the language switcher in the documentation sidebar or header to change your preferred reading language.
- **Bento Navigation:** Use the card layout (Bento Boxes) on the Docs homepage to dive into specific categories like Computer Science, Business, or Finance.

## 3. Exporting the Resume

If you are a recruiter or hiring manager and would like a PDF copy of the resume:
1. Navigate to the **Resume** tab.
2. Click the **Export PDF** or **Download** button.
3. A short form will appear. Please fill in your Name, Company, and Email. (This helps the owner track who is interested!)
4. Click submit. Your PDF download will start automatically.

## Frequently Asked Questions (FAQ)

**Q: I cannot access the `/admin/resume` page. Why?**  
**A:** The admin dashboard is strictly protected. Only the owner of the portfolio (authenticated via a specific Google Account) can access this page. If you are not the owner, you will be redirected to the homepage.

**Q: Why does the URL change when I click Docs?**  
**A:** The main portfolio is an SPA (Single Page Application), but the Documentation is powered by Fumadocs, which uses Server-Side Generation for better SEO and performance. Clicking "Docs" safely bridges you into the documentation engine.

**Q: Does this site work on mobile?**  
**A:** Yes! The entire application is built using responsive Tailwind CSS, ensuring a perfect experience on desktops, tablets, and smartphones.
