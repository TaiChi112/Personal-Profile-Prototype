# Phase 4: Universal Resume Parser

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 3 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** ถ้าผูกขาดให้ดึงข้อมูลเฉพาะ GitHub คนสายอาชีพอื่น (เช่น นักการตลาด ดีไซเนอร์) จะไม่สามารถใช้งานระบบนี้ได้
- **สิ่งที่อยากได้ (The Solution):** ต้องการระบบอัปโหลดไฟล์เรซูเม่แบบมาตรฐาน (PDF, Word, หรือ Markdown) และให้ระบบใช้ AI อ่านเพื่อสกัดข้อมูลประวัติการทำงาน ทักษะ และการศึกษาออกมาจัดเก็บเป็น Vector เพื่อรองรับกลุ่มลูกค้าเป้าหมายทุกสายอาชีพ

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีหน้า Dashboard ให้ผู้ใช้อัปโหลดไฟล์ PDF หรือกรอกข้อมูลด้วยตัวเองได้
- [ ] ระบบสามารถอ่านข้อความจากไฟล์ PDF ได้ครบถ้วน
- [ ] ข้อความที่อ่านได้ถูกนำไปทำ Chunking และ Embedding อย่างถูกต้อง
- [ ] ข้อมูล Vector ถูกผูกกับ `userId` ของผู้อัปโหลด
