# Phase 5: Profile Analytics

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 4 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** ผู้ใช้ที่ยอมจ่ายเงิน (Premium) อยากรู้ว่าโปรไฟล์ที่เขาสร้าง มี HR เข้ามาดูจริงๆ หรือไม่ และเข้ามาดูมากน้อยแค่ไหน
- **สิ่งที่อยากได้ (The Solution):** หน้า Dashboard สถิติสำหรับสมาชิก Premium ที่จะแสดงยอดจำนวนการเข้าชมหน้าโปรไฟล์ในแต่ละวัน และอาจจะแสดงจำนวนครั้งที่ HR พิมพ์โต้ตอบกับ AI Chatbot

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีตาราง `Analytics` ใน Prisma เพื่อบันทึกยอด View
- [ ] ทุกครั้งที่มีคนเปิดหน้า `domain.com/u/[username]` ระบบจะบันทึก Log การเข้าชม (โดยไม่ละเมิด PDPA เช่น บันทึกแค่ IP แบบ Hash หรือแค่บวกเลขเคาน์เตอร์)
- [ ] มีหน้าจอ Dashboard ดึงข้อมูลมาแสดงเป็นกราฟ (ใช้ไลบรารี Recharts)
- [ ] สถิตินี้ดูได้เฉพาะผู้ใช้ Premium เท่านั้น ผู้ใช้ Free จะเห็นข้อความเชิญชวนให้อัปเกรด
