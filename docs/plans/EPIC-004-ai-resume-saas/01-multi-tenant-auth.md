# Phase 1: User Auth & Database Schema

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 1 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** เดิมทีฐานข้อมูลถูกออกแบบมาสำหรับคนเดียว (Single-tenant) หากเปิดให้คนอื่นใช้งาน ข้อมูลจะปะปนกัน
- **สิ่งที่อยากได้ (The Solution):** ต้องการระบบฐานข้อมูลที่ผูกทุกอย่างเข้ากับตาราง User ผู้ใช้งานใหม่สามารถสมัครสมาชิกผ่าน Google หรือ Email ได้ และเมื่อพวกเขาสร้างข้อมูลเรซูเม่ ข้อมูลเหล่านั้นต้องถูกล็อคให้เป็นของพวกเขาคนเดียวเท่านั้น (Data Isolation)

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีตาราง `User`, `Profile`, `VectorData` ใน Prisma Schema โดยทุกตารางต้องมี `userId` ผูกความสัมพันธ์ (Relation) อย่างถูกต้อง
- [ ] ผู้ใช้สามารถกดปุ่ม Login ด้วย OAuth (NextAuth) ได้สำเร็จ
- [ ] เมื่อผู้ใช้เพิ่มข้อมูล Vector ลงในระบบ ข้อมูลนั้นต้องมีรหัสอ้างอิงถึง `userId` ของผู้ใช้คนนั้นเสมอ
