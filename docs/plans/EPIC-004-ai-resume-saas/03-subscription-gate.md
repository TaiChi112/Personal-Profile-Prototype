# Phase 3: Subscription Gate & Feature Flag

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 2 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** หากเปิดให้ทุกคนใช้ AI Chatbot ฟรี แพลตฟอร์มจะแบกรับค่า API มหาศาล
- **สิ่งที่อยากได้ (The Solution):** ต้องการระบบที่แบ่งแยกผู้ใช้ออกเป็น 2 ระดับคือ Free และ Premium ผู้ใช้ระดับ Free จะได้แค่หน้าเว็บเรซูเม่ปกติที่ไม่มีปุ่มแชทบอท ผู้ใช้ระดับ Premium ถึงจะเห็นปุ่มและใช้งาน AI Chatbot ได้

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีคอลัมน์ `tier` ในตาราง `User` (เช่น 'FREE', 'PREMIUM')
- [ ] หน้าเว็บโปรไฟล์มีการเช็คเงื่อนไข (Condition) หากเจ้าของโปรไฟล์เป็น 'FREE' คอมโพเนนต์แชทบอทจะไม่ถูกเรนเดอร์ (ไม่แสดงปุ่ม)
- [ ] หากมีคนพยายามยิง API `/api/chat` ตรงๆ โดยที่เจ้าของโปรไฟล์เป็น 'FREE' ระบบต้อง Block และส่ง 403 Forbidden กลับไป
- [ ] มีปุ่มในหน้า Dashboard ให้ผู้ใช้กดอัปเกรดเป็น Premium (ในเฟสนี้อาจเป็นแค่ปุ่มหลอก หรือ Mock Data ก่อนต่อระบบจ่ายเงินจริง)
