# Phase 2: Dynamic Routing

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 1 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** ปัจจุบันหน้าโปรไฟล์มีแค่หน้าเดียว (Index) ทำให้นำลิงก์ไปแชร์ให้คนอื่นไม่ได้
- **สิ่งที่อยากได้ (The Solution):** ต้องการให้ผู้ใช้แต่ละคนมี URL เป็นของตัวเองในรูปแบบ `domain.com/u/[username]` เพื่อให้ผู้ใช้สามารถนำลิงก์นี้ไปวางใน LinkedIn หรือส่งให้ HR ได้โดยตรง

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีการตั้งค่า Dynamic Route ใน Next.js (เช่น โฟลเดอร์ `app/u/[username]/page.tsx`)
- [ ] เมื่อเข้า URL ระบบจะดึงข้อมูลของ `username` นั้นๆ ออกมาเรนเดอร์หน้าโปรไฟล์ได้อย่างถูกต้อง
- [ ] หากเข้า URL ของ `username` ที่ไม่มีในระบบ จะต้องแสดงหน้า 404 Not Found สวยงาม
- [ ] ระบบแชทบอทในหน้านั้น ต้องดึงข้อมูล Vector ของเจ้าของโปรไฟล์นั้นมาตอบเท่านั้น ห้ามดึงข้อมูลของคนอื่นมาปน
