# Phase 2: Tenant Resolution Logic

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 2 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** บอท LINE มีแค่ตัวเดียว (Official Account กลาง) เวลามีคนทักมา บอทจะไม่รู้ว่าลูกค้านั้นต้องการคุยเพื่อสัมภาษณ์โปรแกรมเมอร์คนไหนในระบบ SaaS ของเรา
- **สิ่งที่อยากได้ (The Solution):** ต้องการระบบที่บังคับให้ผู้ใช้ใส่รหัสอ้างอิง (Reference Code) ในการทักแชทครั้งแรก หรือใช้ฟีเจอร์ Deep Link (LIFF / URL Params) เพื่อผูก `lineUserId` ของผู้ทัก เข้ากับ `userId` ของเจ้าของโปรไฟล์ใน Database

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีตาราง `LineSession` หรือคอลัมน์เก็บข้อมูลว่า `lineUserId` นี้กำลังติดต่อกับ `userId` (เจ้าของโปรไฟล์) คนไหนอยู่
- [ ] เมื่อผู้ทักพิมพ์รหัส (เช่น "REF-DEV-001") บอทจะทำการตรวจสอบและยืนยันว่า "ขณะนี้คุณกำลังสนทนากับเลขาของ [ชื่อเจ้าของโปรไฟล์] ค่ะ"
- [ ] หากไม่ใส่รหัส หรือระบบจำไม่ได้ บอทจะแจ้งให้ใส่รหัสก่อนเริ่มบทสนทนาเสมอ
