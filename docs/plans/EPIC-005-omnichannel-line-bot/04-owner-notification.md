# Phase 4: Owner Notification & Dashboard

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 4 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** บอทปิดการขายได้แล้ว แต่เจ้าของโปรไฟล์ (โปรแกรมเมอร์) ไม่รู้ตัวว่ามีลูกค้าทิ้งข้อมูลติดต่อไว้
- **สิ่งที่อยากได้ (The Solution):** ต้องการหน้า Dashboard ในเว็บแอปพลิเคชัน เพื่อให้เจ้าของโปรไฟล์ล็อกอินเข้ามาดูรายชื่อ Leads ที่บอทหามาให้ได้ พร้อมปุ่มส่งอีเมลกลับไปหาลูกค้า

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีหน้าจอ Dashboard (เช่น `/dashboard/leads`) สงวนไว้สำหรับผู้ใช้ที่ล็อกอินแล้ว
- [ ] หน้าจอดึงข้อมูลจากตาราง `Lead` ที่ตรงกับ `userId` ของตัวเองมาแสดงผลในรูปแบบตาราง (Table)
- [ ] แสดงรายละเอียดครบถ้วน: ชื่อ, อีเมล, รายละเอียดงานที่คุยกับบอท (Requirements)
- [ ] มีการใช้งาน Server Actions ในการดึงข้อมูลเพื่อความปลอดภัยและรวดเร็ว
