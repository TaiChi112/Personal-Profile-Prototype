# Phase 2: กลุ่มเป้าหมายและกลไกนิเวศ (Target & Ecosystem Mechanics)

**สถานะ:** Visionary Blueprint

## 1. Milestone Goal
โครงการนี้เป็นระบบ Two-sided Marketplace (หรืออาจจะ Three-sided) ที่แต่ละฝ่ายได้ประโยชน์เกื้อกูลกัน:
1. **SME / NGO (Demand Side):** ธุรกิจขนาดเล็กที่ต้องการระบบซอฟต์แวร์ (เช่น ระบบจัดการสต๊อก, เว็บแอป) แต่มีงบประมาณจำกัด ไม่สามารถจ้าง Software House ใหญ่ๆ ได้
2. **CS Students / Junior Developers (Supply Side):** นักศึกษาฝึกงาน หรือคนจบใหม่ที่ต้องการ "ประสบการณ์จริง (Real-world Experience)" เพื่อนำไปใส่พอร์ตโฟลิโอสมัครงาน
3. **Enterprise Recruiters / HR (Monetization Side):** บริษัทใหญ่ที่ต้องการจ้างงาน แต่ไม่อยากเสียเวลา/งบประมาณ ในการคัดกรองเรซูเม่ปลอมหรือสัมภาษณ์คนที่ทำงานจริงไม่เป็น

## 2. Acceptance Criteria
1. **SME** โพสต์ความต้องการด้วยภาษาทั่วไป (Plain Language)
2. **AI Platform** รับความต้องการไปวิเคราะห์ และแปลงเป็นเอกสาร Requirement (SRS) พร้อมสถาปัตยกรรม
3. **Junior Devs** เข้ามารับงาน (Bounties) โดยถูกบังคับให้เขียนโค้ดตามกรอบของ AI
4. **AI Platform** ตรวจสอบโค้ด หากผ่านเกณฑ์ ISO ก็จะส่งมอบซอฟต์แวร์คุณภาพสูงให้ SME
5. **Junior Devs** ได้ประวัติผลงานบันทึกลงในระบบ
6. **Recruiters** จ่ายเงินซื้อข้อมูลหรือจ่ายค่าหัวคิว เพื่อดึงตัว Junior ที่มีผลงานโดดเด่นไปร่วมงาน
