# Phase 2: React Flow Canvas Integration

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 2 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** ได้ข้อมูล JSON มาแล้ว แต่ยังไม่มีกระดาน (Canvas) สำหรับนำเสนอให้ผู้ชมได้เห็นและเล่นกับมัน
- **สิ่งที่อยากได้ (The Solution):** นำข้อมูล Node และ Edge มาเรนเดอร์ลงในคอมโพเนนต์ React Flow บนหน้าเว็บโปรไฟล์ เพื่อให้ผู้เข้าชมสามารถเลื่อนจอ (Pan) และซูมเข้าซูมออก (Zoom) เพื่อดูทักษะทั้งหมดได้

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] นำไลบรารี `@xyflow/react` มาสร้างคอมโพเนนต์กระดาน (Canvas) บนหน้าโปรไฟล์
- [ ] สร้างโหนดรูปแบบพิเศษ (Custom Node Component) ให้ดูทันสมัยเข้ากับธีมของเว็บ แทนที่รูปแบบโหนดสี่เหลี่ยมสีขาวธรรมดา
- [ ] มีระบบ Mini-map อยู่ที่มุมจอ เพื่อให้ผู้ใช้รู้ว่ากำลังดูส่วนไหนของแผนผัง
- [ ] เมื่อโหลดหน้าเว็บ แผนผังจะถูกจัดกึ่งกลาง (Fit View) อัตโนมัติ
