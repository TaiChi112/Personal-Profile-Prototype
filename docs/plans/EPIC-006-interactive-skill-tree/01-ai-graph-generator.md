# Phase 1: AI Graph Generator

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 1 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** การจะให้ผู้ใช้มานั่งเขียน JSON โครงสร้าง Node (จุด) และ Edge (เส้นเชื่อม) ด้วยตัวเอง เป็นเรื่องที่ยากเกินไปและผิดพลาดได้ง่าย
- **สิ่งที่อยากได้ (The Solution):** ระบบอัจฉริยะที่ผู้ใช้แค่อัปโหลดเรซูเม่ (หรือใช้ข้อมูลจากระบบ Universal Parser เดิม) แล้ว AI จะวิเคราะห์และสร้างโครงสร้าง JSON ที่แบ่งลำดับชั้น (Hierarchy) อย่างถูกต้องให้เอง เช่น พ่อ (Programming) -> ลูก (JavaScript, Python) -> หลาน (React, Django)

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีการเรียกใช้งาน AI (Vercel AI SDK `generateObject`) พร้อมกำหนด Zod Schema สำหรับ Node และ Edge อย่างเข้มงวด
- [ ] AI สามารถดึงหมวดหมู่ทักษะหลักและย่อยออกจากข้อความเรซูเม่ดิบได้อย่างสมเหตุสมผล
- [ ] ข้อมูล JSON ที่ได้ ต้องเข้ากันได้กับรูปแบบโครงสร้างของไลบรารี React Flow โดยตรง
- [ ] ระบบมีการคำนวณตำแหน่งพิกัดเริ่มต้น (X, Y) ของแต่ละโหนดให้อัตโนมัติ เพื่อไม่ให้โหนดไปกองทับกัน
