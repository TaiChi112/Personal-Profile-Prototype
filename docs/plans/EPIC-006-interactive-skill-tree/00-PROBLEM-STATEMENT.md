# Epic: Interactive Skill Tree

## The Problem
Standard text-based lists of skills are boring and fail to capture a recruiter's attention or demonstrate a developer's creativity and UX/UI capabilities.

## Desired Outcome
A highly engaging, interactive "RPG-style" Skill Tree that visually maps out the candidate's skills, creating a massive "wow factor" for profile visitors.

## Core Capabilities
- **Automated Graph Generation:** Convert resume text into nodes and edges automatically.
- **Interactive Node Rendering:** Display nodes on a canvas with pan/zoom support.
- **Smooth Animations:** Expandable sub-nodes with fluid motion upon interaction.

## Constraints & Environment
- Must perform smoothly on mobile devices.
- Visuals cannot clutter the screen or overwhelm the user.
