# Phase 3: Interactivity & Animations

**สถานะ:** Backlog
**ความเชื่อมโยง:** Milestone 3 (Master Plan)

---
## 1. มุมมองผู้ใช้งาน (User Story & Problem)
- **ปัญหา (The Problem):** แผนผังดูสวยงาม แต่เป็นแค่ภาพนิ่ง หากมีข้อมูลทักษะเยอะมาก กระดานจะดูรกและลายตา
- **สิ่งที่อยากได้ (The Solution):** ตอนเริ่มต้น ให้แสดงเฉพาะโหนดหัวข้อหลัก (เช่น Frontend, Backend) เมื่อผู้ใช้คลิกที่โหนดนั้น โหนดลูก (ทักษะย่อย) จึงจะค่อยๆ ขยายโผล่ออกมาพร้อมแอนิเมชันที่นุ่มนวล

## 2. เกณฑ์การตรวจรับงาน (Acceptance Criteria)
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีระบบจัดเก็บสถานะ (State) ว่าโหนดใดถูกคลิกเปิด (Expanded) หรือปิด (Collapsed)
- [ ] หากโหนดยังไม่ถูกคลิก โหนดลูกและเส้นเชื่อมทั้งหมดของมันจะถูกซ่อนไว้
- [ ] เมื่อกดคลิก โหนดลูกจะปรากฏขึ้นมาพร้อมแอนิเมชัน (ใช้ `framer-motion` เพื่อความนุ่มนวล)
- [ ] มีการจัดเรียงพิกัดตำแหน่งใหม่ (Auto-layout) เล็กน้อย หากโหนดลูกขยายออกมาแล้วบังกันเอง
