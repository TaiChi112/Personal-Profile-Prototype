# การเริ่มต้นใช้งานแพลตฟอร์ม TaiChi112

ยินดีต้อนรับสู่ **TaiChi112 Platform Hub** แพลตฟอร์มนี้ถูกออกแบบมาเพื่อรวบรวมองค์ความรู้จากหลากหลายสาขาวิชาให้อยู่ในอินเทอร์เฟซเดียวที่ใช้งานง่ายและเป็นระเบียบ

## 🧭 พื้นฐานการนำทาง

เพื่อป้องกันปัญหาข้อมูลล้นเกิน (Cognitive Overload) เนื้อหาทั้งหมดจะถูกแบ่งออกเป็น **โดเมนที่แยกขาดจากกัน (Isolated Domains)**

1. **Root Toggle (เมนู Dropdown):** ที่ด้านบนสุดของ Sidebar จะมีเมนู Dropdown สำหรับสลับไปยังหมวดหมู่หลัก เช่น `Computer Science`, `Business`, หรือ `Finance`
2. **การแยกส่วนเนื้อหา:** เมื่อคุณเลือกโดเมนใดโดเมนหนึ่ง Sidebar จะเปลี่ยนไปแสดง *เฉพาะ* เนื้อหาที่เกี่ยวข้องกับวิชานั้นๆ ทันที ทำให้ไม่มีเนื้อหาวิชาอื่นมาปะปน
3. **Bento Cards:** คุณสามารถใช้การ์ด Bento แบบโต้ตอบได้ในหน้า [แนะนำเบื้องต้น](./) เพื่อกระโดดเข้าไปยังโดเมนต่างๆ ได้อย่างรวดเร็ว

## 🔍 การค้นหา

ใช้ปุ่มลัด `Cmd + K` (สำหรับ Mac) หรือ `Ctrl + K` (สำหรับ Windows) เพื่อเปิดหน้าต่างค้นหาหลัก ระบบค้นหาจะทำการสแกนเนื้อหาจากทุกโดเมน คุณจึงสามารถค้นหาสิ่งที่ต้องการได้ทันทีแม้จะไม่ได้อยู่ในโดเมนนั้นๆ ก็ตาม

## 🌗 การแสดงผล (Theme)

TaiChi112 Docs รองรับทั้งโหมดสว่าง (Light) และโหมดมืด (Dark) ระบบจะปรับตามการตั้งค่าของเครื่องคุณโดยอัตโนมัติ แต่คุณก็สามารถเปลี่ยนโหมดเองได้ผ่านไอคอนที่อยู่ด้านล่างสุดของ Sidebar
