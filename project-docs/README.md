# Software Development Life Cycle (SDLC) Documentation

Welcome to the project's documentation hub. This directory contains all standard SDLC documents, organized by role.

## 📁 Directory Structure

- **/pm**: Project Management (PRD, Roadmap, Release Notes)
- **/developer**: Technical specifications (Architecture, API, Database)
- **/designer**: UX/UI standards (Design System, User Flows)
- **/qa**: Testing and quality assurance (Test Plan, Test Cases)
- **/user**: End-user facing documentation (Manuals, FAQs)

*Note: For AI Agent specific rules and constraints, please refer to the `.docs/` directory.*
