# Phase 2: Glassmorphic UI & Widgets

**Status:** Backlog
**Link:** Problem Statement

---
## 1. Milestone Goal
- **The Problem:** Raw aggregated data needs to be parsed into quick, digestible insights and presented in an aesthetically pleasing way.
- **The Solution:** Build a responsive grid layout over a vibrant background. Create individual "glass" widgets that process the raw data into summaries (e.g., summing income/expenses, counting tasks by status) and display them beautifully.

## 2. Acceptance Criteria
- [ ] Establish a global layout featuring a vibrant, multi-color gradient background.
- [ ] Create a reusable CSS pattern for "Glassmorphism" (combining semi-transparent white backgrounds, blur filters, and subtle white borders) applied to widget containers.
- [ ] Build a Clock Widget that displays the current time and date in real-time.
- [ ] Build a Finance Widget that accepts transaction data, calculates total income and total expense, and displays the sums with appropriate color coding.
- [ ] Build a Kanban Widget that accepts task data, counts the volume of tasks in "To Do", "In Progress", and "Done" states, and lists the titles of currently active tasks.
