# Phase 2: Dynamic Visual Feedback UI

**Status:** Backlog
**Link:** Problem Statement

---
## 1. Milestone Goal
- **The Problem:** Presenting raw numbers to users is unhelpful; they need visual context to understand what their BMI and BMR actually mean for their health.
- **The Solution:** Build a responsive, highly visual dashboard that binds to the biometric engine. The UI should dynamically change colors and labels based on the health category, making the data instantly interpretable.

## 2. Acceptance Criteria
- [ ] Create a clean input form for capturing age, gender, height, and weight.
- [ ] Design a dedicated display card for BMI that dynamically updates its color scheme (e.g., green for normal, red for obese) based on the computed category.
- [ ] Design a dedicated display card for BMR that clearly communicates the base calorie burn per day.
- [ ] Ensure the entire layout is mobile-responsive and visually engaging.
