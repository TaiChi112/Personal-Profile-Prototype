# Epic: OmniQA Sentient (Micro-App)

## The Problem
Testing in staging environments only catches so much; true architectural flaws often reveal themselves under live production traffic. Additionally, as large enterprises adopt visual AI workflows, individual teams recreate the same architectural flowcharts (like "Standard Checkout") from scratch, leading to wasted effort and technical debt.

## Desired Outcome
An "OmniQA Sentient" micro-app (Phase 5). This application demonstrates the final evolutionary step of the ecosystem:
1. **Live Sentinel:** A production-monitoring tool that overlays real-time "traffic heatmaps" directly onto the architectural flowchart to visualize bottlenecks.
2. **Self Optimizer:** An autonomous maintenance loop where the AI actively cleans technical debt and stages Git Pull Requests for human approval.
3. **Agentic Hub:** An internal marketplace where teams can publish, share, and download reusable state machine architectures (flowcharts) to standardize enterprise processes.

## Core Capabilities
- **Live Data Overlay Graph:** A visual presentation layer utilizing React Flow that binds architectural node styling to a mock "live traffic" state. It dynamically injects intense CSS properties (like glowing red box-shadows) to visualize production bottlenecks.
- **Autonomous Maintenance Pipeline:** A static simulation UI that visualizes the AI's ability to act as a junior developer: identifying deprecated code, rewriting it, and packaging it into a human-readable Pull Request interface for approval.
- **Architectural Component Marketplace:** A grid-based layout representing the "Agentic Hub". It lists reusable architectural flows as "packages" (with metadata like downloads and stars) and utilizes gamified telemetry (Hub Score) to encourage cross-team collaboration.

## Constraints & Environment
- The application MUST operate entirely on the client-side for demonstration purposes, heavily relying on mocked state booleans (`isLive`, `approved`) and static grid data arrays rather than true live traffic ingestion or Git integration.
- The UI MUST utilize profound, vibrant dark-mode aesthetics (deep indigo, fuchsia gradients) with advanced framer-motion interactions to convey the highly advanced "Sentient" nature of the tooling.
