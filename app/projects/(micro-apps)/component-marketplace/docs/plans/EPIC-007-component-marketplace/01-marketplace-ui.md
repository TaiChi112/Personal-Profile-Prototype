## 1. Milestone Goal
- **ปัญหา (The Problem):** ต้องการพื้นที่สำหรับนำเสนอผลงาน Component ต่างๆ ที่เขียนขึ้นมา เพื่อให้คนที่เข้ามาดูพอร์ตโฟลิโอรู้ว่าเรามีซอร์สโค้ดขาย
- **สิ่งที่อยากได้ (The Solution):** หน้าเว็บ Micro-App ที่มีหน้าตาเหมือนแกลเลอรีสินค้า (Grid Layout) แสดงรูปภาพตัวอย่าง ชื่อ Component คำอธิบายสั้นๆ และราคา เมื่อกดเข้าไปจะเข้าสู่หน้าแสดงรายละเอียดของ Component นั้นๆ
