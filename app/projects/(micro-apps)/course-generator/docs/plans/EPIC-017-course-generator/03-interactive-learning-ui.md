## 1. Milestone Goal
- **ปัญหา (The Problem):** แค่อ่านสรุปยาวๆ มันน่าเบื่อเกินไป อยากให้การเรียนสนุกเหมือนเล่นแอปเรียนภาษา (เช่น Duolingo)
- **สิ่งที่อยากได้ (The Solution):** หน้าต่าง UI สไตล์ Dashboard ด้านบนแสดงสรุปเนื้อหาทีละบท (Tabs) และด้านล่างเป็นดง "การ์ดคำถาม (Flashcards)" ที่ผู้ใช้สามารถกดคลิกเพื่อให้การ์ดพลิกโชว์คำตอบด้านหลังได้

## 2. Acceptance Criteria
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] นำข้อมูล JSON จาก Phase 2 มาเรนเดอร์ในหน้าจอผลลัพธ์
- [ ] สร้างคอมโพเนนต์ `Flashcard` ที่รองรับ CSS 3D Transform (`rotateY`) เมื่อเกิด event `onClick`
- [ ] มีปุ่ม "Mark as Learned" ในการ์ดแต่ละใบ เพื่อให้ผู้ใช้รู้สึกว่าตัวเองมีความก้าวหน้าในการเรียน
- [ ] รองรับการใช้งานผ่านโทรศัพท์มือถือ (Mobile Responsive) ได้อย่างลื่นไหล
