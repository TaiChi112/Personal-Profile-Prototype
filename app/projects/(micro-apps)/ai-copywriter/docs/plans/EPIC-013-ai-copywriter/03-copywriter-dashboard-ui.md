# Phase 3: Copywriter Dashboard UI

**สถานะ:** Backlog
**ความเชื่อมโยง:** Problem Statement

---
## 1. Milestone Goal
- **ปัญหา (The Problem):** หน้าต่าง UI ไม่สวยงาม ทำให้ลูกค้าไม่เชื่อมั่นว่าเครื่องมือนี้เป็นของระดับโปร
- **สิ่งที่อยากได้ (The Solution):** หน้า Dashboard ที่ออกแบบมาให้ใช้งานง่าย แบ่งเป็น 2 โซน โซนซ้ายสำหรับวาง URL (และอาจจะให้พิมพ์ข้อความเสริมได้) โซนขวาเป็นพื้นที่แสดงผลลัพธ์ที่แบ่งเป็นแท็บ (Tabs) ชัดเจนระหว่าง Facebook, TikTok, และ Email 

## 2. Acceptance Criteria
> *เมื่อ AI ทำงานเสร็จ ต้องสามารถติ๊กถูกทุกข้อนี้ได้*
- [ ] มีหน้าเว็บ `/projects/ai-copywriter`
- [ ] มีช่อง Input รับ URL ขนาดใหญ่ และปุ่ม "Generate Ads"
- [ ] เมื่อ AI ส่งผลลัพธ์กลับมา ฝั่งขวาจะแสดงเนื้อหาในรูปแบบแท็บ (Tabs Component)
- [ ] มีปุ่ม "Copy" แปะอยู่มุมขวาบนของแต่ละแท็บ เพื่อให้ลูกค้านำข้อความไปใช้งานต่อได้สะดวก
- [ ] มีอนิเมชัน Loading ที่สวยงาม ระหว่างรอระบบขูดเว็บและรอ AI คิดข้อความ (อาจใช้เวลา 10-20 วินาที)
