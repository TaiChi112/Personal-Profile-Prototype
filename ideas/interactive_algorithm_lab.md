# Interactive Algorithm Lab (Frontend & CS Logic)

**Description:** A visualizer for computer science algorithms (e.g., Sorting, Pathfinding). Showcases deep understanding of Data Structures and Algorithms, along with complex React state management.

**Details:**
- สิ่งที่ได้โชว์: ความเข้าใจใน CS Data Structures อย่างลึกซึ้ง และความสามารถในการเขียน React State ที่ซับซ้อน หรือแม้แต่ HTML5 Canvas
- UX: ผู้ใช้สามารถกดปุ่มสุ่มตัวเลข แล้วกด Play เพื่อดู Animation ของ Bubble Sort แบบ Real-time
