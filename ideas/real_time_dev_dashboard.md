# Real-time Dev Dashboard (API Integration)

**Description:** A real-time analytics dashboard pulling data from external APIs (GitHub commits, WakaTime coding stats, Spotify). Showcases OAuth, Webhooks, and 3rd-party REST API integrations.

**Details:**
- สิ่งที่ได้โชว์: การคุยกับ External 3rd-party APIs, Webhooks, และ OAuth
- UX: โชว์กราฟการ Commit GitHub ย้อนหลัง, สถิติภาษาที่ใช้โค้ดดิ้ง (ดึงจาก WakaTime), หรือแม้แต่โชว์ว่า "ตอนนี้ Rawin กำลังฟังเพลงอะไรอยู่บน Spotify"
