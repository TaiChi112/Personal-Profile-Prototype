# AI Resume Assistant (GenAI / RAG)

**Description:** A conversational mini-app where recruiters can chat with an AI trained exclusively on your resume, skills, and past projects. Showcases RAG (Retrieval-Augmented Generation) and API integration.

**Details:**
- สิ่งที่ได้โชว์: ความสามารถในการเชื่อมต่อ API (เช่น OpenAI หรือ Gemini), การทำ RAG (Retrieval-Augmented Generation), และ Vercel AI SDK
- UX: Recruiter สามารถพิมพ์ถามได้เลยว่า "Rawin เคยเขียน Python โปรเจกต์ไหนบ้าง?" หรือ "ทักษะเด่นที่สุดคืออะไร?"
